# P07 — SeedWater native Moxi replay

Thirteen genuine AppKit `cacheDisplay` captures from the external application
`moxi-sws`, using the existing slideshow manifest v1/render
schema. Each is labeled **offscreen-render**, not compositor or physical-input
evidence. The thirteen PNGs are retained with this manifest; generated
`index.html` remains ignored.

The sequence covers asymmetric overlay, frame/contrast/zoom and native pan,
seed placement/movement plus polygon watershed, semantic undo/redo, atomic
save/reopen, delayed/stale/failed/cancelled computation, explicit corrupt-file
recovery, resize, two-owner isolation and disposal/recreation. AppKit pointer
callbacks are injected into the real view; pixels are generated by Moxi native
composition/controls, not mocked. Selected cell measurements and contour are
linked to actual labels. 168 captured pixel centers are checked against the
scientific raster at multiple zooms, with the PNG's embedded display profile
converted to sRGB only for comparison; original captures remain unchanged.

## Reproduction

Prepare the application environment, Moxi's locked Pixi toolchain and the pinned scientific reference following the external application's README. From the application checkout, set `MOXI_ROOT` to a clean Moxi checkout at the revision in `build.json`, `MOXI_TOOLCHAIN` to its installed Pixi environment, `SWS_REFERENCE` to the pinned reference checkout and `SWS_LEGACY_PYTHON` to the matching reference interpreter.

```sh
export MOJO="$MOXI_TOOLCHAIN/bin/mojo"
export MODULAR_HOME="$MOXI_TOOLCHAIN/share/max"
export MOXI_ROOT SWS_REFERENCE SWS_LEGACY_PYTHON
PYTHONPATH=. .venv/bin/python scripts/evidence.py
```

The script records [both source inventories](source-hashes.json), builds the application, compares pinned reference results, runs the replay and emits an offline slideshow at `artifacts/demo-slideshows/sws-native/index.html` in the Moxi checkout. The captured synthetic timings are described in `metrics.json`. Physical editing, assistive technology, independent scientific acceptance, real external image stacks, power-loss durability and release packaging remain open.
