PatternAuthor’s modelWork transferred to the framework
Retained objectsCreate widgets, handle events, set properties.Widget lifetime, layout and rendering; application synchronization remains explicit.
Property bindingsThis property follows that expression; edits may flow back.Observation and propagation; authors choose direction and commit timing.
Fine-grained computationsReactive values feed dependent expressions.Dependency tracking and targeted execution; authors respect tracking boundaries.
Re-evaluated descriptionsDescribe UI from the current state.Reconciliation with retained UI; authors respect identity and repeatability.
Messages / MVUInteractions emit messages that update the model.Message processing and effect execution; composition routing remains a cost.
Immediate APIRun UI calls against application values.Interpret calls and retain interaction state; IDs and sequencing matter.

Re-evaluating a description ≠ recreating widgets ≠ repainting the entire screen. An immediate API also need not imply a stateless implementation or continuous rendering.
