What is counted? Five output expressions per editor. Marko counters are inserted after compilation; its actual DOM values are checked. Solid uses actual reactive effects without DOM. Mojo uses a separate projection harness.

These are work counts, not execution times. Upstream propagation, comparisons, allocation and layout are excluded. Zero evaluated leaves does not mean zero CPU work.

All versions preserve private drafts, reject stale/replaced-document edits, and pass undo and keyed lifecycle checks. A retained callback can still commit after its editor is removed.
