# I10 — A laboratory where observations become tools

Let an investigation produce a reusable tool as a byproduct.

Status: speculative product concept, captured October 20, 2026.
Origin: Second brainstorm, idea 1; recommended data-workbench experiment. This is an idea brief, not an implementation commitment.

## Experience

Brush an unusual cluster in the existing workbench, pull the selection onto a canvas, and name it. Choose frozen membership or a live rule. Attach a hypothesis, fit an editable model, inspect residuals, and compare alternatives. Eventually connect observations to a specimen in 3D and package the useful controls as a failure-pattern instrument.

Persistent cohorts, provenance, model editing, and instrument packaging are new work. Keep stable observation identity through filtering. A fitted model and a scientific explanation are different claims.

## Smallest useful experiment

Extend the workbench in stages: persistent named cohort first; then one explicit model and residual view; then alternatives and a fixed panel configuration. The first stage does not depend on math or 3D shipping.

Confidence: **Moderate**. Confidence rises if users complete a real investigation and reuse its panel with less glue than a bespoke screen; poor state coherence would undermine the framework hypothesis.
